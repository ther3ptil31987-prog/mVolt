# v0.50.1

v0.50.1 brings extended tuning limits, new fan controls and a compact dashboard,
alongside more telemetry and improvements to profiles and responsiveness.
Changes since v0.47.3:

### Tuning and limits

- Added **Extend limits using BIOS override** for memory offset, power and board input current, with BIOS import, an experimental different-BIOS option and recovery actions. This does **NOT** flash the card's BIOS.
- Added **Board input current** in amperes, with profile and Tuning Overview support, including higher current targets where supported.
- Fixed watt-based power control and percentage-limit conversion errors. Watt targets now also coordinate the board-power request on supported GPUs.
- Improved recovery when saved limits are missing or changed, and kept ordinary tuning available when it does not depend on extended ranges.

### Fans and cooling

- Added experimental **GPU fan policy editing** alongside the mVolt software curve. Edit each policy's three temperature points while its speed values stay fixed, or restore its saved original settings.
- Added GPU fan policies to profiles, including startup **Apply, then exit**. Software fan curves still need mVolt+ running.
- Reworked the fan editor with direct temperature and duty fields, clearer controller selection and preserved drafts between views.
- Added a separate **Thermal limit** control in °C, with profile support and Reset. This adjusts the requested GPU thermal limit independently of fan curves and fixed thermal inputs.

### Interface and profiles

- Added **Minimal / Compact**, with separate collapsible fan and thermal input controls. Layout and colors are shared across GPUs.
- Added independent overvoltage switches and clearer **Applied / Allowed** readings in Standard's voltage tiles.
- Unified menus, typography and tooltips; improved scaling, scrolling, maximize/restore and window-close responsiveness.
- Improved V/F curve selection, dragging and preservation of pending edits.
- Made profile saves more responsive, refined previews and grouped Update / Save as new actions. Added a global **Toggle Boost Lock** shortcut under Settings → Hotkeys.

### Telemetry

- Added **GPU info** with silicon binning readings, firmware-reported NVVDD/MSVDD Vrel and their separate offsets.
- Expanded **Temperatures** with additional GPU and memory sensor readings where supported.
- Expanded RTSS options with profile and Boost Lock state, memory clock, temperatures, fan duty/RPM, power versus limit, GPU load and VRAM usage. Improved alignment, units and handling of unavailable readings.

### Compatibility and startup

- Improved compatibility across supported GPU and driver combinations, including power, current, memory and voltage controls.
- Improved startup handling for disconnected GPUs and updates to installed startup copies. Improved preservation of profile changes made from the command line.

See the [user guide](https://github.com/b00nz/mVolt/blob/main/docs/guide.md) for setup and the [BIOS-copy guide](https://github.com/b00nz/mVolt/blob/main/docs/guide.md#bios-copy)
before using Extend limits. Feature availability depends on the GPU, BIOS and driver.
